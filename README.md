# TCM-study-notes (中医数字化学习与推演库)

## 关于我
洛阳职业技术学院 中医专业 大一学生。一名试图用“极客思维”重构中医知识体系的探索者。

## 仓库定位
打破传统死记硬背，建立一个**可溯源、可推演、数字化的中医第二大脑**。
将传统中医哲学（医易同源）与现代AI工具结合，记录真实病案推演、批判性思考与复盘。

## 我的学习工作流 (Workflow)
1. **输入:** 课堂理论学习 + 经典古籍阅读。
2. **推演:** 针对真实病案，建立中医基础理论模型。
3. **验证:** 借助 AI 检索引擎进行逻辑辅助与文献匹配。
4. **批判:** 结合临床常识与《中药学》禁忌，对AI结论进行纠错。
5. **沉淀:** 将最终思考归档至本仓库。

## 目录结构
*   `01_医案推演` - 真实病例的中医辨证与AI复盘记录。
*   `02_中医基础` - 《中基》核心概念的知识图谱梳理。
*   `03_本草禁忌` - 《中药学》药物偏性与禁忌的极客笔记。
